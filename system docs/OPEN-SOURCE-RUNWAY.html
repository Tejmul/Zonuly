Open source cannot save this placement season.

It can do something else, and that thing is worth doing — but the calendar has to be said out loud first, because every program you named has already closed for 2026.

The short answer

Do not slow the placement push. That is the thing with a real deadline. Every open-source stipend on this page pays out between May and September 2027, and the earliest application window opens in mid-January.

Start contributing anyway, in the evenings, to exactly one project. Not for the stipend. For the thing that cost you the OpenHands referral: a maintainer wrote back to say he doesn't know you. One merged pull request in a 92,948-star repository fixes that, and it is two weeks of evenings, not three months.

A merged PR is a resume line in this placement season — not in 2027. That is the near-term payoff, and it is the reason to start now rather than in January.

Section three

One project. Which one.

You asked to stop spreading across fifty communities and pick one thing. Agreed — but there are two different bets hiding inside "contribute to open source", and they do not pay the same way.

OpenHands

the pick

Job-shaped. No stipend, but the shortest path to someone deciding you are worth hiring.

  • A maintainer has already replied to you. That is the hardest part, and it is done.
  • AI coding agents — your actual domain, not a detour into something you'd have to learn first.
  • 21 open good-first-issues right now, in a repo with 92,948 stars.
  • Funded: $23.8M raised, and their last posted engineering role stated $170K–$275K.
  • A merged PR here is usable in your cold emails next month, not next September.

A CNCF or GSoC organisation

Stipend-shaped. Real money, but a cold start and a long wait.

  • Nobody there knows you. You would be starting the Engel conversation again from zero.
  • Contributions compound into an LFX or GSoC application — OpenHands contributions do not, because it is a company and takes part in neither.
  • First payout is May 2027 at the earliest.
  • Worth doing after you are placed, or in January if placements have resolved by then.

If placements are still unresolved in January, switch the evening hours to an LFX project and apply. The two bets are sequential, not simultaneous — picking both at once is how the fifty-communities problem comes back.

Section four

This week

  1. Send Engel the reply.

    Name a specific issue in it. The whole value of that thread is that a maintainer already knows your name.

  2. Read the issue properly before you touch code.

    #15532, consolidating the duplicated src/context/ and src/contexts/ directories, is mechanical and hard to get wrong. #15567 is the backup.

  3. Run the project locally and make it work before you change anything.

    Most first-time contributors fail here, not at the code. Budget an evening for setup alone.

  4. One PR. Small, complete, with the issue number in the description.

    A tidy small PR that merges beats an ambitious one that stalls in review. The goal this month is merged, not impressive.

  5. Keep applying, at full speed, the entire time.

    This is the part that is easy to let slip once open source starts feeling like progress. It is the part with the deadline.
